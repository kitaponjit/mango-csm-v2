# Warranty Item Ticket 02 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Each task follows test-driven development and must report RED and GREEN evidence. Do not commit, push, or create a PR because repository governance requires explicit authorization.

**Goal:** Add typed, contract-safe Warranty Item Create/Edit behavior to the approved T1 page.

**Architecture:** Pure TypeScript contract, draft, lookup, permission, and form-controller modules isolate backend and application behavior from a thin Vue SFC. T1 list rows contribute only immutable code to Edit; detail data is normalized before becoming a draft and explicit DTO mappers whitelist mutation fields.

**Tech Stack:** Nuxt 4, Vue 3, TypeScript 5.9, Vitest 4, existing `$xt` transport adapter.
