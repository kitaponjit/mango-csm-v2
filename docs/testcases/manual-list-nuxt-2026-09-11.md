# เอกสารทดสอบ (Test Cases) — รายการอัพเดทโปรแกรมบน Nuxt

| หัวข้อ | รายละเอียด |
|---|---|
| **เรื่องที่แก้ไข** | เพิ่มหน้ารายการอัพเดทโปรแกรมบนเส้นทางเป้าหมาย Nuxt โดยคงสัญญาการค้นหา รายการแยกโมดูล และเอกสารแนบของระบบเดิม |
| **ขอบเขตที่กระทบ** | การตรวจ session ภายใน, การค้นหาตามวันที่/Revision, tab โมดูล, ตารางผลลัพธ์, เอกสารแนบ, ภาษาไทย/อังกฤษ และ responsive |
| **หน้าจอ / เมนู** | Nuxt: `/csm-next/manual/` (`Nuxt/app/pages/manual/index.vue`); หน้าระบบเดิมที่ต้องไม่เปลี่ยน: `/page/manual/v_csm_manual_list/` (`Website/Scripts/App/Application/Components/Pages/Manual/v_csm_manual_list.vue`) |
| **Endpoint ที่เกี่ยวข้อง** | `/CSM/Manual/ManualReadList`, `/CSM/Manual/ManualReadListV2`, `/CSM/Manual/ReadPicture`, `/Api/File/DownLoad` |
| **Area / Controller / Action** | Area `CSM`, Controller `Manual`, Actions `ManualReadList`, `ManualReadListV2`, `ReadPicture`; เจ้าของ backend อยู่นอก checkout นี้และไม่มีการแก้ backend |
| **วันที่จัดทำ** | 2026-09-11 |

## รายการ Test Case

### TC-01: เปิดหน้าด้วย session ภายในและค้นหาช่วงวันที่เริ่มต้น

| รายการ | รายละเอียด |
|---|---|
| **ประเภท** | Happy path |
| **เงื่อนไขเริ่มต้น (Pre-condition)** | Login ระบบเดิมสำเร็จและมี session ภายในที่ยังใช้งานได้; API มีข้อมูลอย่างน้อย 2 โมดูลในเดือนปัจจุบัน |
| **ข้อมูลทดสอบ (Test Data)** | ข้อมูล GL 1 รายการและ AP 1 รายการในเดือนปัจจุบัน |

**ขั้นตอนการทดสอบ (Test Steps):**

- [ ] **1.** เปิด `/csm-next/manual/`
  - _ผลลัพธ์ที่คาดหวัง:_ แสดงชื่อหน้า `รายการอัพเดทโปรแกรม`; เลือก `ค้นหาตามวันที่`; วันที่เริ่มต้นเป็นวันที่ 1 ของเดือนปัจจุบันและวันที่สิ้นสุดเป็นวันปัจจุบัน
- [ ] **2.** รอให้การค้นหาเริ่มต้นเสร็จ
  - _ผลลัพธ์ที่คาดหวัง:_ เรียก `CSM/Manual/ManualReadList` โดยส่งวันที่รูปแบบ `DD/MM/YYYY`; แสดง tab ครบ `ALL, BD, OF, PO, IC, AP, AR, FA, GL, PM, SE, RT, MA, MRP, EVAL, RE`
- [ ] **3.** ตรวจ tab `ALL` และตาราง
  - _ผลลัพธ์ที่คาดหวัง:_ ยอด ALL เท่ากับผลรวมยอดทุกโมดูล; ตารางแสดงลำดับ, Revision No., หัวข้อ และวันที่; วันที่อยู่ในรูปแบบ `DD/MM/YYYY`
- [ ] **4.** กด tab `GL`
  - _ผลลัพธ์ที่คาดหวัง:_ ตารางเหลือเฉพาะแถวที่ module เป็น `GL` และยอดบน tab ตรงกับจำนวนจาก API

### TC-02: ค้นหาตาม Revision และเงื่อนไข

| รายการ | รายละเอียด |
|---|---|
| **ประเภท** | Happy path |
| **เงื่อนไขเริ่มต้น (Pre-condition)** | อยู่ที่หน้ารายการอัพเดทโปรแกรมและ session ยังใช้งานได้ |
| **ข้อมูลทดสอบ (Test Data)** | Revision เริ่มต้น `R-2026-01`, สิ้นสุด `R-2026-09`; เงื่อนไข `ระหว่าง`, `มากกว่า`, `น้อยกว่า`, `เท่ากับ` |

**ขั้นตอนการทดสอบ (Test Steps):**

- [ ] **1.** เลือก `ค้นหาตาม Revision` และกรอก Revision เริ่มต้น/สิ้นสุดตามข้อมูลทดสอบ
  - _ผลลัพธ์ที่คาดหวัง:_ แสดงช่อง Revision และรายการเงื่อนไขทั้ง 4 ค่า โดยไม่แสดงช่องวันที่
- [ ] **2.** เลือก `ระหว่าง` แล้วกด `ค้นหา`
  - _ผลลัพธ์ที่คาดหวัง:_ เรียก `CSM/Manual/ManualReadListV2` ด้วย `condition=between` และค่าที่กรอกครบถ้วน; ผลลัพธ์กลับมาเลือก tab ALL
- [ ] **3.** ทดสอบซ้ำด้วย `มากกว่า`, `น้อยกว่า`, `เท่ากับ`
  - _ผลลัพธ์ที่คาดหวัง:_ ส่งค่า `more_than`, `less_than`, `equal` ตามลำดับ และแสดงผลตามข้อมูลตอบกลับ
- [ ] **4.** ค้นหาด้วยช่วงที่ไม่มีข้อมูล
  - _ผลลัพธ์ที่คาดหวัง:_ แสดง `ไม่พบรายการอัพเดทซอฟต์แวร์` โดยหน้าไม่ค้างและยังค้นหาใหม่ได้

### TC-03: เปิดและดาวน์โหลดเอกสารแนบ

| รายการ | รายละเอียด |
|---|---|
| **ประเภท** | Happy path |
| **เงื่อนไขเริ่มต้น (Pre-condition)** | ตารางมีอย่างน้อย 1 รายการที่มีไฟล์รูปภาพและไฟล์เอกสารแนบ |
| **ข้อมูลทดสอบ (Test Data)** | ไฟล์ `.png` 1 ไฟล์และ `.pdf` 1 ไฟล์ของรายการเดียวกัน |

**ขั้นตอนการทดสอบ (Test Steps):**

- [ ] **1.** กดข้อความหัวข้อของรายการ
  - _ผลลัพธ์ที่คาดหวัง:_ เปิด dialog เอกสารแนบและเรียก `CSM/Manual/ReadPicture` ด้วย `job_no`, `module`, `revision` ของแถวที่เลือก
- [ ] **2.** ตรวจรายการไฟล์ใน dialog
  - _ผลลัพธ์ที่คาดหวัง:_ ไฟล์รูปภาพมีภาพตัวอย่าง; ไฟล์ชนิดอื่นแสดงชื่อ/คำอธิบาย; ทุกไฟล์มี `เปิดไฟล์` และ `ดาวน์โหลด`
- [ ] **3.** เปิดไฟล์และตรวจ URL ดาวน์โหลด
  - _ผลลัพธ์ที่คาดหวัง:_ URL ใช้ `/Api/File/DownLoad?id=...`; ปุ่มดาวน์โหลดเพิ่ม `download=true`; ค่า id ถูก encode และไม่เผย credential ใน URL
- [ ] **4.** ปิด dialog ด้วยปุ่มปิดและปุ่ม Escape
  - _ผลลัพธ์ที่คาดหวัง:_ dialog ปิดได้ทั้งสองวิธีและกลับสู่รายการเดิม

### TC-04: แสดงสถานะผิดพลาดและลองใหม่

| รายการ | รายละเอียด |
|---|---|
| **ประเภท** | Regression |
| **เงื่อนไขเริ่มต้น (Pre-condition)** | จำลอง API รายการหรือเอกสารแนบตอบ error/network failure |
| **ข้อมูลทดสอบ (Test Data)** | API error ที่มีข้อความ เช่น `ไม่สามารถเชื่อมต่อบริการได้` |

**ขั้นตอนการทดสอบ (Test Steps):**

- [ ] **1.** เปิดหน้าหรือกดค้นหาขณะ API รายการตอบ error
  - _ผลลัพธ์ที่คาดหวัง:_ แสดงสถานะผิดพลาดพร้อมรายละเอียดและปุ่ม `ลองอีกครั้ง`; ไม่แสดงข้อมูลเก่าเป็นผลลัพธ์ใหม่
- [ ] **2.** ให้ API กลับมาทำงานแล้วกด `ลองอีกครั้ง`
  - _ผลลัพธ์ที่คาดหวัง:_ โหลดและแสดงรายการได้โดยไม่ต้อง refresh ทั้งหน้า
- [ ] **3.** เปิดหัวข้อที่ API เอกสารแนบตอบ error
  - _ผลลัพธ์ที่คาดหวัง:_ dialog แสดงสถานะผิดพลาดของเอกสารแนบโดยไม่ทำให้หน้ารายการเสียหาย

### TC-05: ป้องกันการเรียก API เมื่อไม่มี session หรือ session หมดอายุ

| รายการ | รายละเอียด |
|---|---|
| **ประเภท** | Regression |
| **เงื่อนไขเริ่มต้น (Pre-condition)** | ทดสอบครั้งแรกโดยไม่มี session; ครั้งที่สองให้ API ตอบ HTTP 401; ครั้งที่สามให้ API ตอบ HTTP 403 |
| **ข้อมูลทดสอบ (Test Data)** | ไม่มี credential, credential หมดอายุ, credential ที่ไม่มีสิทธิ์ |

**ขั้นตอนการทดสอบ (Test Steps):**

- [ ] **1.** เปิด `/csm-next/manual/` โดยไม่มี session ภายใน
  - _ผลลัพธ์ที่คาดหวัง:_ redirect ไป login path ที่กำหนดและไม่เรียก endpoint `CSM/Manual/*`
- [ ] **2.** เปิดหน้าด้วย session ที่ API ตอบ 401
  - _ผลลัพธ์ที่คาดหวัง:_ มอง session เป็น invalid และ redirect ไป login path; ไม่ลบหรือเปลี่ยนกลไก token ของระบบเดิม
- [ ] **3.** เปิดหน้าด้วย session ที่ API ตอบ 403
  - _ผลลัพธ์ที่คาดหวัง:_ แสดงข้อความไม่มีสิทธิ์/ผิดพลาดในหน้าและไม่ redirect เป็น session หมดอายุ

### TC-06: ภาษา การใช้งานด้วยคีย์บอร์ด และ responsive

| รายการ | รายละเอียด |
|---|---|
| **ประเภท** | Regression |
| **เงื่อนไขเริ่มต้น (Pre-condition)** | มี session และข้อมูลผลลัพธ์; ทดสอบ desktop และหน้าจอกว้าง 390px |
| **ข้อมูลทดสอบ (Test Data)** | ภาษาไทยค่าเริ่มต้น; preference `EN` สำหรับภาษาอังกฤษ |

**ขั้นตอนการทดสอบ (Test Steps):**

- [ ] **1.** เปิดหน้าโดยไม่มีค่าภาษา แล้วเปิดซ้ำด้วย preference `EN`
  - _ผลลัพธ์ที่คาดหวัง:_ ครั้งแรกแสดงภาษาไทยและข้อความ legacy สำคัญตรงเดิม; ครั้งที่สองแสดงข้อความอังกฤษ โดยโครงสร้าง/ข้อมูลไม่เปลี่ยน
- [ ] **2.** โฟกัส tab แล้วกดลูกศรซ้าย/ขวา, Home และ End
  - _ผลลัพธ์ที่คาดหวัง:_ focus และรายการที่แสดงย้ายตาม tab อย่างวนรอบ; Home ไป ALL และ End ไป RE
- [ ] **3.** เปิดหน้าที่ความกว้าง 390px และทำการค้นหา
  - _ผลลัพธ์ที่คาดหวัง:_ ฟอร์มเรียงหนึ่งคอลัมน์, ปุ่มค้นหาใช้งานได้, หน้าไม่ล้น viewport; tab/table เลื่อนแนวนอนได้ภายในส่วนของตน
- [ ] **4.** เปิดเส้นทางเดิม `/page/manual/v_csm_manual_list/`
  - _ผลลัพธ์ที่คาดหวัง:_ หน้า Vue 2 เดิมยังเปิดและทำงานได้; route เดิมไม่ถูก redirect หรือลบจากการเพิ่ม Nuxt route
